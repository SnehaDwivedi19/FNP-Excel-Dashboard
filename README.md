# FNP Excel Dashboard

## About the Project

This project is an interactive sales dashboard created using Microsoft Excel as part of my learning and practice in data analysis and dashboard development.

The project was created by following a guided YouTube tutorial and practicing the concepts using the FNP dataset.

## Tools Used

* Microsoft Excel
* PivotTables
* PivotCharts
* Slicers
* Excel formulas
* Data analysis and visualization

## What I Learned

Through this project, I practiced:

* Working with and analyzing data in Excel
* Creating PivotTables and PivotCharts
* Using slicers for interactive filtering
* Creating KPIs and summary metrics
* Building an interactive dashboard
* Presenting data through charts and visualizations

## Project Files

* FNP_Excel_Dashboard.xlsx — Complete Excel workbook containing the data, PivotTables, and dashboard
